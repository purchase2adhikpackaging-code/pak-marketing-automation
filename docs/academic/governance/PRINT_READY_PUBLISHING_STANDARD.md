# PAK Print-Ready Academic Publishing Standard

**Status:** Governance mirror for fast retrieval  
**Source authority:** Section 26 of `docs/academic/PAK_ACADEMIC_CURRICULUM_STUDY_MATERIAL_BLUEPRINT_PRD.md`  
**Rule:** This mirror is retrieval convenience only; it must not independently redefine policy. If any discrepancy appears, the master PRD governs until synchronized.

## 1. Mandatory Scope

All PAK academic material is designed for both digital delivery and professional physical printing. Curriculum architecture and publication architecture are therefore developed together. Required figures, drawings, tables, exercises, forms, workbook pages, practical records and front/back matter must be identified during chapter design, not added as an afterthought.

## 2. Semester-/Module-Wise Publication Rule

For semester-based programmes, **every subject in every semester must ultimately have its own complete print-ready subject textbook PDF**, visibly identifying PAK, programme and code, academic year, semester, subject and code, edition/version, and publication date/year.

Where applicable, separate print-ready publications are required for:

- Practical / Workshop Manual
- Student Workbook
- Practical Journal / Logbook
- Instructor Guide
- Teaching Slides
- Question Bank
- Theory Examination
- Practical Assessment Pack
- Answer Key / Marking Guide

Certificate programmes use the equivalent module/block rule. A module may be a separate module publication or an explicitly mapped unit of a programme textbook, but practical manuals and journals/logbooks must remain separately printable where learners need writing space, workshop evidence or instructor sign-off.

## 3. Mandatory Textbook Front Matter

A full subject textbook should normally include, in controlled order:

1. Front Cover
2. Inside Title Page
3. Publication / Edition / Version Information
4. Copyright and Permitted-Use Notice
5. Academic Approval / Review / Revision Record
6. Preface or Foreword where applicable
7. About the Programme / Subject
8. Introduction
9. How to Use This Book
10. Programme → Semester → Subject Mapping
11. Subject Purpose and Scope
12. Prerequisites
13. Learning Outcomes
14. Table of Contents / Index of Chapters
15. List of Figures
16. List of Tables
17. List of Drawings / Schematics where appropriate
18. Abbreviations and Acronyms
19. Symbols, Units and Notation where relevant
20. Safety / Regulatory / Competency Boundary Notice where relevant

## 4. Standard Chapter Anatomy

Default chapter anatomy:

1. Chapter Number and Title
2. Chapter Purpose
3. Learning Objectives / Learning Outcomes
4. Prerequisite Knowledge
5. Key Terms
6. Main Theory / Concept Explanation
7. Required Diagrams / Drawings / Graphics / Schematics
8. Tables / Data / Formulae / Worked Examples where relevant
9. Railway Application Examples
10. Safety-Critical Notes / Warnings where relevant
11. Regulatory / Standard Context where relevant
12. Practical / Workshop / Laboratory Link where relevant
13. Case Study / Failure Example / Operational Scenario where relevant
14. Knowledge Checkpoints
15. Chapter Summary
16. Key Takeaways
17. Review Questions
18. MCQs / Short Questions / Numerical Problems as appropriate
19. Assignment / Activity / Practical Task where appropriate
20. References / Source Notes where needed

**Visual rule:** no chapter should remain text-only when a diagram, drawing, schematic, process flow, annotated photograph, chart or table would materially improve technical understanding.

## 5. Mandatory Back Matter

Depending on subject type, include:

- cumulative subject summary / revision guide;
- glossary of technical terms;
- master abbreviations/acronyms list if appropriate;
- formula sheet / symbols list;
- references / bibliography;
- legislation, standards and technical-reference register;
- recommended further reading;
- appendices;
- selected data tables;
- subject/keyword index for substantial books;
- figure/table index where useful;
- revision history / edition record.

Controlled answer keys and rubrics belong in instructor material unless an exercise is explicitly designed for self-study.

## 6. Workbook Standard

A workbook is an active-learning publication, not a shortened textbook. It may include chapter worksheets, fill-in diagrams, terminology exercises, calculation sheets, component-identification pages, defect-identification exercises, inspection checklists, drawing-reading tasks, tables to complete, case-study response sheets, MCQs/short answers, assignments, revision tests, self-assessment and instructor feedback space.

Adequate handwritten working space must be deliberately designed into print layouts.

## 7. Practical Manual and Journal / Logbook Standard

Practical activity templates should include as applicable:

1. Activity / Experiment / Job Number
2. Title and Objective
3. Linked Subject/Chapter/Learning Outcome
4. Required Prior Knowledge
5. Safety / Hazard Identification
6. PPE Requirements
7. Tools, Instruments, Equipment and Materials
8. Approved Data / Drawing / Work Instruction Reference
9. Setup / Pre-Task Checks
10. Procedure / Method
11. Observation / Measurement Table
12. Calculations / Results
13. Acceptance / Evaluation Source where applicable
14. Defects / Findings / Nonconformities
15. Student Conclusion / Reflection
16. Housekeeping / Restoration / Post-Task Check
17. Instructor Questions
18. Student Signature / Date
19. Instructor Verification / Sign-Off
20. Reassessment / Corrective Action Record where applicable

The Student Journal/Logbook must preserve a chronological, printable record of practical work, workshop/site exposure, competencies attempted, instructor verification and learner reflections.

## 8. Instructor Guide Standard

Instructor-only material may include lesson plans, contact-hour allocation, teaching notes, demonstrations, equipment preparation, safety control points, learner misconceptions, worked solutions, answer keys, rubrics, practical observation checklists, oral-question banks, remediation guidance, marking schemes, and references to controlled manufacturer/ECM/workshop instructions where legitimate.

## 9. Drawings, Diagrams, Graphics and Illustration Standard

Technical visuals are academic content, not decoration. Use as appropriate:

- system block diagrams;
- engineering line drawings;
- simplified CAD-style drawings;
- exploded component views;
- sectional/cutaway illustrations;
- electrical schematics;
- pneumatic/hydraulic schematics;
- wiring diagrams;
- process flowcharts;
- maintenance decision trees;
- inspection-zone maps;
- failure/defect illustrations;
- annotated photographs;
- dimensional sketches;
- charts and graphs;
- tables and matrices;
- timelines;
- infographics where genuinely useful.

Every figure needs a unique figure number and caption. Every table needs a unique table number and title. Drawings/schematics must remain legible at final printed size.

Safety-critical or manufacturing-sensitive visuals created only for explanation must be labelled **Illustrative / Training Use Only** unless they are approved controlled material legitimately authorized for reproduction.

## 10. Print Image and Graphics Quality

- Vector artwork preferred for diagrams, line drawings, symbols and schematics.
- Raster photographs/images should normally be at least **300 dpi at final print size**.
- High-detail line art should target **600 dpi or vector equivalent** where practical.
- Graphics must remain understandable in grayscale and must not depend on colour alone.
- Thin lines, tiny labels and low-contrast text must be avoided.
- Photographs must be technically relevant and annotated when instructional.
- Visual assets require source/licence/ownership records.
- PAK-created original diagrams are preferred wherever feasible.

## 11. Page Design and Print Format Baseline

Default unless superseded by an approved publication specification:

- A4 (210 × 297 mm)
- Portrait orientation for standard books
- Landscape pages selectively for large tables/schematics
- Binding-aware inner/gutter margin
- Print-safe outer/top/bottom margins
- 3 mm bleed for full-bleed covers/pages where required
- Consistent running headers/footers
- Page numbering
- Programme/subject identification where useful
- Consistent heading, caption, table, equation and callout styles

Workbooks/journals must prioritize handwriting and page opening; practical manuals must prioritize workshop/lab usability and durability.

## 12. PDF Production Standard

Final PDFs must be fit for professional printing and digital study:

- embedded fonts;
- high-resolution print assets;
- correct page size/bleed;
- digital bookmarks and navigable contents;
- searchable/selectable text wherever possible;
- metadata containing title, subject code, programme code, edition and version;
- vector-preserving export;
- print proofing before release;
- no accidental printer marks in student digital editions;
- printer-specific PDF/X export, preferably PDF/X-4 or printer-required equivalent, for final production.

Digital-reading and printer-delivery PDFs may be separate exports from the same approved source layout.

## 13. Cover Design Standard

Every independently printed subject/module publication requires a professional cover with PAK identity, programme title/code, subject/module title/code, academic year and semester/block, edition/version and an academically appropriate technical visual. Spine/back-cover treatment is required when binding/page count justifies it. Barcode/ISBN/publication identifiers may be added if adopted later.

## 14. Typography, Equations, Units and Notation

- SI units are default unless railway practice justifies another unit.
- Symbols are defined at first use and collected when calculation-heavy.
- Equations are typeset clearly and numbered when cross-reference is needed.
- Decimal, unit, date and number formatting must be consistent.
- Abbreviations are expanded on first use and included in the abbreviations section.
- Polish/EU terminology and accepted railway English must be standardized portfolio-wide.

## 15. Accessibility and Grayscale Robustness

Use readable typography, adequate contrast, descriptive captions and logical heading hierarchy. Colour-coded information must remain understandable in grayscale and by learners with colour-vision limitations.

## 16. Copyright, Licensing and Source Control

- Use original PAK-authored or properly licensed/authorized material.
- Do not reproduce proprietary standards in full.
- Do not copy manufacturer manuals, drawings or textbooks without permission.
- Explain standards in original educational language and cite/reference the governing source.
- Controlled manufacturer/ECM drawings or procedures may be reproduced only with legitimate permission and appropriate publication status.
- Maintain a source register for every book during development.

## 17. Safety-Critical Illustration and Procedure Rule

Educational drawings, photographs, tables or worked procedures must not be presented as approved operational/maintenance/manufacturing instructions when they are illustrative.

Where safety-critical limits, tolerances, torque values, test pressures, electrical settings, brake criteria, wheelset dimensions, weld acceptance levels, NDT acceptance criteria or operating instructions are stated, the exact governing controlled source must be identified and current applicability verified before publication.

## 18. File Naming and Versioning

Baseline examples:

- `PAK-D01-Y1-S1-D01-101-TEXTBOOK-v1.0.pdf`
- `PAK-D01-Y1-S1-D01-105-PRACTICAL-MANUAL-v1.0.pdf`
- `PAK-D01-Y1-S1-D01-105-STUDENT-WORKBOOK-v1.0.pdf`
- `PAK-D01-Y1-S1-D01-105-PRACTICAL-JOURNAL-v1.0.pdf`
- `PAK-D01-Y1-S1-D01-105-INSTRUCTOR-GUIDE-v1.0.pdf`
- `PAK-C03-B01-C03-101-MODULE-BOOK-v1.0.pdf`

Programme, academic period, subject/module code, publication type and version must always be inferable from filenames.

## 19. Book Production Gate

Full textbook writing may start only after subject/module architecture, chapter architecture, learning outcomes, practical needs, visual requirements, standards/reference families, assessment placeholders, safety-critical flags, publication types and print-layout requirements are mapped.

Final print production requires academic QA, technical review, visual QA, citation/reference review, copy-editing, pagination/index generation, print-proof review and version approval.
