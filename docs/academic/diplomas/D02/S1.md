# PAK-D02 — Year 1 / Semester 1

**Semester:** Mechanical Engineering & Railway Foundations  
**Master PRD source:** §18.2  
**Publishing governance:** `../../governance/PRINT_READY_PUBLISHING_STANDARD.md`

## Semester Objective

Establish the mathematical, mechanical, materials, drawing, workshop and railway-system foundations required for applied mechanical specialization.

| Code | Subject | Classification | Orientation | Prerequisite |
|---|---|---|---|---|
| D02-101 | Applied Engineering Mathematics & Engineering Mechanics I | Core | Theory + Problem Solving | None |
| D02-102 | Engineering Physics, Heat & Energy Fundamentals | Core | Theory + Laboratory | None |
| D02-103 | Engineering Drawing, CAD, Geometric Dimensioning & Technical Documentation | Core | Theory + CAD Lab | None |
| D02-104 | Materials Science, Metallurgy & Corrosion for Railway Engineering | Core | Theory + Laboratory / Demonstration | None |
| D02-105 | Workshop Technology, Metrology, Fitting & Machine Tools I | Practical Core | Workshop-Dominant | None |
| D02-106 | Railway Systems Fundamentals, Safety & Technical Communication | Core | Theory + Demonstration + Practical Exercises | None |

## Semester Progression Logic

`D02-101` establishes force, equilibrium, motion and calculation skills; `D02-102` introduces energy/heat principles; `D02-103` builds drawing/CAD/GD&T competence; `D02-104` supplies metallurgy/material behaviour; `D02-105` develops practical measurement/fitting/tool skills; and `D02-106` embeds the railway, safety and professional context.

## Publication Rule

Each subject must later have its own semester-wise print-ready textbook PDF, with lab/workshop/manual/workbook/journal and technical-visual deliverables mapped before writing.
